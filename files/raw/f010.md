# 기출/족보 시험정보 모음 (선배 후기 종합)

> 여러 학기 선배들의 시험 후기와 기출 메모를 모은 족보 모음.
> 과목별 출제 경향 요약. (출처: 학과 단톡방 공유 자료, 에브리타임 시험정보 게시글 정리)

## 1. 경영학원론 (김도현 교수)

- 중간: 4지선다 20문제 + 서술 2문제, 기말: 4지선다 25문제 + 서술 3문제 — 형식 거의 고정 ★
- **단골 출제**: 포터 5 Forces (매년 서술형 1번), SWOT 매트릭스 전략(SO/WO/ST/WT), 4P 가격전략 4종 구분 ★★
- 2025년 중간 서술 1번: "5 Forces를 국내 카페 프랜차이즈 산업에 적용" — 산업 적용형 서술 자주 나옴
- 교수님이 수업 중 "이거 시험에 나옵니다" 말하면 진짜 나옴. 슬라이드 별표 친 부분 위주로 정리
- 기말은 중간 범위에서 재무제표·NPV 계산 객관식으로도 나옴

## 2. 공학수학1 (이정훈 교수)

- 중간: 6문제 주관식, 90분. 1계 미분방정식 4문제 + 2계 동차 2문제 구성
- **단골**: 적분인자, 완전미방 판정, 냉각법칙 응용(중간), 감쇠진동 판정(기말) ★★
- 기말에 라플라스 변환 대문제 (초기값 문제에 적용) 거의 매년 출제 ★
- 공식노트 A4 1장 손필기 허용 → 전 학기 공식을 다 정리해 들어가는 게 핵심
- 과제 문제가 시험과 유형 동일한 경우 많음. 과제 풀이 그대로 복습 ★

## 3. 실용영어 (Sarah Kim 강사)

- 기말 구두시험(Oral Test): 개인별 10분 면담 — 자기소계 + 캠퍼스 문제에 대한 의견 + 간단한 후속 질문 2개
- **준비물**: 발표 주제를 다시 말로 풀어보는 연습 (발표 내용 그대로 물어봄) ★
- 퀴즈는 매 2주 어휘 리스트에서 10문제. LMS 오디오로 미리 듣기 가능
- 출석 절대 지키기 — 결석 4회 초과 F, 지각 3회=결석 1회 규칙 실제로 엄격히 적용함

## 4. 대학글쓰기 (박서연 교수)

- 기말은 에세이 100% (시험 없음). 유사도 검사 30% 초과 재작성 규칙 실제 적용됨
- 반론 검토(6점)를 빼먹는 사람 많음 — 반례 1개 이상은 필수 ★
- 개요 첨삭(5/25) 받아가면 점수 확 올라감. 초고 첨삭도 신청 추천

## 5. 공통 팁

- 부산대 LMS 공지사항에 과제 안내 올라오므로 푸시 알림 켜두기
- 학과 학생회 자료실(과방)에 기출 족보 바인더 있음 — 대여 가능
- 중간고사 기간 도서관 스터디룸은 2주 전부터 예약해야 함
