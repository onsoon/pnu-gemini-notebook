# [과제 공지] 실용영어 조별 영어 발표 안내 (12주차)

**게시일**: 2026-04-27 (LMS 공지사항)
**과목**: 실용영어 (GEN120-08) / Sarah J. Kim 강사

## 1. 발표 개요

- **주제**: "A Solution to a Campus Problem at Pusan National University"
  (부산대 캠퍼스에서 겪는 문제 하나를 골라, 원인을 분석하고 해결책을 제안하는 발표)
- **형식**: 조별 발표, 조당 15~20분 (조원 4명, 1인당 4~5분, 반드시 전원 발표)
- **일정**: 12주차 수업 시간 (5월 25일, 27일 양일에 걸쳐 실시)

## 2. 조 구성 및 일정

| 일정 | 내용 |
|---|---|
| 4월 28일(화) | 조 편성 완료 (LMS 조별 게시판에 조원 이름 등록) |
| 5월 4일(월) | 주제 확정 및 역할 분담 (회의록 #1 제출) |
| 5월 11일(월) | 개요(Outline) 초안 제출 (회의록 #2 제출) |
| 5월 18일(월) | 리허설 (수업 시간, 강사 피드백) |
| 5월 25일(월)~27일(수) | 본 발표 |

## 3. 발표 요건

1. 슬라이드 8장 이내 (영어로 작성, 글자 크기 28pt 이상)
2. 발표 대본은 외우지 말고 요약 카드만 사용 가능
3. 인터뷰·설문 등 조사 활동을 1개 이상 포함 (사진/데이터 슬라이드로 제시)
4. Q&A: 발표 후 다른 조에서 질문 1개 이상 → 답변 준비 필수
5. 모든 조원이 각각 4분 이상 speaking 할 것

## 4. 평가 루브릭 (25점 만점)

| 항목 | 배점 | 기준 |
|---|---|---|
| 내용 (문제·원인·해결책 논리) | 8점 | 근거와 예시의 타당성 |
| 언어 (발음, 문법, 유창성) | 8점 | 이해 가능성과 정확성 |
| 전달 (시선, 제스처, 슬라이드 활용) | 5점 | 청중과의 소통 |
| 협업 (회의록, 역할 분담, Q&A) | 4점 | 조 기여도 |

## 5. 유의사항

- 조원 간 기여도 편차가 크면 개별 점수 차등 반영
- 발표 당일 무단 불참 시 해당 조원 0점 처리
- 대본 100% 암기 발표는 오히려 감점 요소 (자연스러운 전달이 목표)
- 장비 문제 예방을 위해 전날 이메일로 슬라이드 파일 제출 요망
