# 경영학원론 강의 슬라이드 핵심 요약 (1주차~6주차)

> 강의 슬라이드 PDF 6개 파일에서 핵심 개념만 발췌·요약한 학습 자료.
> ★ 표시는 교수님이 수업 중 "시험에 나온다"고 강조한 부분.

## 1주차: 경영학이란

- 경영(Management): 조직의 목표를 효과적(effective)·효율적(efficient)으로 달성하기 위한 계획·조직·지휘·통제 과정 ★
- 기업가 정신(entrepreneurship)과 경영자의 역할 구분

## 2주차: 경영환경 분석

- ★ PEST 분석: Political(정치), Economic(경제), Social(사회), Technological(기술)
- 거시환경 vs 과업환경(산업환경) 구분 ★
- 이해관계자(stakeholder): 주주, 종업원, 고객, 공급자, 지역사회, 정부

## 3주차: 포터의 5 Forces ★★ (중간고사 단골)

1. 기존 경쟁자 간의 경쟁 강도
2. 신규 진입자의 위협
3. 대체재의 위협
4. 공급자의 교섭력
5. 구매자의 교섭력

- 각 요인이 "강해지는 조건"을 외울 것 ★ (예: 전환비용 낮을수록 구매자 교섭력 ↑)

## 4주차: SWOT 분석과 전략 수립

- SWOT: 내부 환경(강점 S / 약점 W) + 외부 환경(기회 O / 위협 T)
- ★ 전략 도출 매트릭스: SO 전략(공격적), WO(방어적 변신), ST(다각화), WT(축소·철수)
- BSC(균형성과표): 재무·고객·내부프로세스·학습과성장 관점

## 5주차: 마케팅 관리(1) — STP ★★

- Segmentation(세분화): 인구통계적/지리적/심리적/행동적 변수 ★
- Targeting: 세분시장 매력도 평가 → 표적시장 선택 (무차별/차별/집중적 마케팅)
- Positioning: 소비자 마음속에 차별화된 위치 설정, 포지셔닝 맵

## 6주차: 마케팅 관리(2) — 4P ★

- Product: 제품 계층(핵심·실제·부가), 제품 수명주기(도입기/성장기/성숙기/쇠퇴기) ★
- Price: ★ 원가추가 / 침투 / 프리미엄 / 손실인도 가격전략 (구분 문제 단골)
- Place: 유통 채널 구조 (직접/간접, 다단계)
- Promotion: 광고, PR, 인적판매, 판매촉진

## 시험 대비 체크리스트

- [ ] PEST와 5 Forces를 실제 산업에 적용해 설명할 수 있는가 ★
- [ ] SWOT 4가지 매트릭스 전략을 예시로 들 수 있는가 ★
- [ ] STP를 브랜드 사례로 풀어 설명할 수 있는가 ★★
- [ ] 4P 가격전략 4가지를 구분할 수 있는가 ★
