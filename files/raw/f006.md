# 공학수학1 중간고사 기출문제 (2024학년도 1학기)

**과목**: 공학수학1 (MTH205) / **담당**: 이정훈 교수
**범위**: 1계 미분방정식 전체 + 2계 선형 동차 미분방정식
**형식**: 6문제, 각 문제 배점 다름, 총 100점 / 시간 90분 / 공식노트 A4 1장 허용

## 문제

**1. (10점)** 다음 미분방정식의 일반해를 구하시오.
  dy/dx = (1 + y²) / (1 + x²)

**2. (15점)** 적분인자법으로 다음 방정식을 풀어라.
  x y' + 2y = x⁴ e^(−x²) ... (x > 0)

**3. (15점)** 다음을 완전미분방정식으로 만들기 위한 적분인자를 구하고, 해를 구하시오.
  (x² + y)dx + x dy = 0

**4. (15점)** 살균제가 주입되는 탱크의 혼합 문제. 유입 농도와 유출 속도가 주어졌을 때, t분 후 탱크 내 염의 양을 나타내는 1계 선형 미분방정식을 세우고 풀어라.

**5. (20점)** 2계 선형 동차 미분방정식의 세 가지 경우(실근이 서로 다른 경우, 중근, 허근)에 대해 각각 일반해의 형태를 쓰고, 다음 방정식을 풀어라.
  y'' − 4y' + 13y = 0

**6. (25점)** 질량-스프링 감쇠 진동 시스템. m, c, k가 주어졌을 때
  (1) 감쇠의 종류(과감쇠/임계감쇠/저감쇠)를 판정하는 기준을 서술하고
  (2) 주어진 수치의 경우를 판정하며
  (3) 해를 구하고 운동의 특성(주기, 진폭 감소)을 설명하시오.

## 선배 풀이 메모 (족보에 함께 첨부되었던 필기)

- 1번: arctan 형태, 변수분리 뒤 양변 arctan 씌우면 끝
- 2번: 양변 x로 나누면 y' + (2/x)y = x³e^(−x²) → 적분인자 μ = x²
- 5번: 특성방정식 r² − 4r + 13 = 0 → r = 2 ± 3i → 저감쇠 진동 형태
- 6번: 판별식 c² − 4mk 부호가 핵심 ★ 작년에도 이 유형 나옴
