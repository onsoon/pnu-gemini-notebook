# 부산대 대동제 부스 운영 비품 렌털 업체별 견적 비교표 (가상)

> 실습용 가상 견적 데이터. 실제 업체와 무관.
> 실습 3에서 이 데이터를 업로드한 뒤 "수식이 작동하는 엑셀(XLSX) 시뮬레이터" 생성을 요청한다.

## 기본 수량 (학과 부스 1개 기준)

| 품목 | 기본 수량 |
|---|---|
| 천막(3×3m) | 2개 |
| 듀라테이블 | 6개 |
| 플라스틱 의자 | 30개 |
| 앰프(스피커 세트) | 1식 |

## 업체별 단가표 (1일 기준, 부가세 별도)

| 품목 | 부산렌탈(주) | 금정이벤트 | 효원비품 |
|---|---|---|---|
| 천막 3×3m (개당) | 80,000원 | 75,000원 | 90,000원 |
| 듀라테이블 (개당) | 4,000원 | 5,000원 | 3,500원 |
| 플라스틱 의자 (개당) | 800원 | 700원 | 900원 |
| 앰프 1식 (일당) | 60,000원 | 55,000원 | 70,000원 |
| 배송 설치비 (건) | 50,000원 | 무료 | 30,000원 |
| 파손 보증금 (환불) | 100,000원 | 150,000원 | 80,000원 |

## 업체별 조건

- 부산렌탈(주): 3일 이상 대여 시 천막 10% 할인
- 금정이벤트: 총액 50만원 이상 시 배송비 무료
- 효원비품: 학생회 제출 서류(재학증명) 제시 시 앰프 10% 할인

## 엑셀 시뮬레이터 요구사양

- 품목별 수량 입력 칸 → `=SUM(단가×수량)` 자동 계산
- 업체별 소계 → `=IF(조건, 할인가, 원가)` 반영
- 최종 추천 조합 → 가장 저렴한 업체 조합 `=IF(MIN(...))` 표시
- 총지출 예산 80만원 초과 시 경고 표시 (`=IF(총액>800000,"초과","적정")`)
