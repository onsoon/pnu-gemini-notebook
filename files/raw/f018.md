# 부산대 북문 상권 현황 보고 (가상)

> 실습용 가상 데이터. 실제 통계와 다름.

## 개요

- 상권 범위: 북문 로데오거리 일대 (점포 약 210개)
- 유동인구: 평일 1.8만 명, 주말 1.5만 명 (2026.9 조사, 가상)
- 임대료(1층 기준): 평당 30~42만원 (정문보다 25~30% 낮음)

## 공실 현황

- 공실률: 6.8% (전년 7.9% → 소폭 개선)
- 공실 업종: 주로 2층 학원가 (2개)
- 1층 로데오거리는 회전율 높음 (신규 창업 활발)

## 북문 상권 특징

1. **학생 수요 중심**: 밥집·술집·카페 비중 70%, 저가 업종 생존력 강함
2. **주거 밀집**: 북문 뒤편 원룸촌 — 심야 수요 안정적
3. **임대료 부담 적음**: 정문 대비 저렴해 소상공인 진입장벽 낮음

## 정문과의 비교 요약

| 구분 | 정문 | 북문 |
|---|---|---|
| 공실률 | 11.2% (높음) | 6.8% (안정) |
| 임대료 평당 | 45~60만 | 30~42만 |
| 유동 패턴 | 지나가는 길 | 체류형 먹거리 |
| 약점 | 임대료·유동 감소 | 상권 규모 작음 |
