**학수번호**: GEN120-08

**담당강사**: Sarah J. Kim (sarahkim@pusan.ac.kr)

**수강대상**: 2026학번 신입생 전체 (교양필수 지정 과목)

## 1. 교과목 개요

대학생활과 직업 세계에서 요구되는 실용 영어 능력을 기른다. 듣기·말하기 중심의 수업으로, 일상 대화, 학술 발표, 토론, 이메일 작성 등을 실습한다. 영어로만 진행되는 수업(English-only policy)이 특징이며, 페어/그룹 활동이 많다.

**주교재**: 경희대 외국어교육원편, 『Practical English for University Life』, 형설출판사
**보조자료**: 강의 LMS에 주차별 오디오·비디오 자료 업로드

## 2. 평가 방법

| 항목 | 반영 비율 |
|---|---|
| 출석 및 수업 참여 (페어 활동 포함) | 20% |
| 어휘·듣기 퀴즈 (5회) | 15% |
| 에세이 1편 (영작) | 15% |
| 조별 영어 발표 | 25% |
| 기말 구두시험 (Oral Test) | 25% |

## 3. 주차별 강의 계획

| 주차 | 주제 | 핵심 활동 |
|---|---|---|
| 1주 | Orientation: English-only 수업 규칙, ice-breaking |
| 2주 | Campus Life: 강의실 표현, 질문하기 |
| 3주 | Making Friends: 자기소개, small talk |
| 4주 | Library & Online Resources | 정보 요청 대화 |
| 5주 | Email Writing: 교수님께 이메일 쓰기 | 실제 이메일 작성 실습 |
| 6주 | Vocabulary Quiz 1 + 듣기 연습 |
| 7주 | Midterm Check: 에세이 개요 작성 워크숍 |
| 8주 | **에세이 제출 마감** (My University Life, 500단어) |
| 9주 | Group Project 1: 발표 주제 선정, 역할 분담 |
| 10주 | Presentation Skills: 슬라이드, 시선, 제스처 |
| 11주 | Group Project 2: 리허설 및 피드백 |
| 12주 | **조별 영어 발표** (5분×조원당) |
| 13주 | Debate Basics: 찬반 입장 표현 |
| 14주 | Job Interview English: 모의 면접 |
| 15주 | **기말 구두시험 (Oral Test)**: 개인별 10분 면담 |

## 4. 수업 운영 규칙

1. 수업 중 영어만 사용 (한국어 사용 시 참여도 감점)
2. 스마트폰은 사전 활동 용도로만 허용
3. 결석 4회 초과 시 F 처리 (지각 3회 = 결석 1회)
4. 발표는 조별 미팅 로그(회의록) 제출 병행
