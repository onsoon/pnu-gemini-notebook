# IT 기업 직무별 신입 자격요건 가이드 (가상)

> 실습용 가상 정리 자료. 실제 기업과 무관함.

## 개발(백엔드/프론트엔드)

- 필수: 자료구조·알고리즘 코딩테스트, 1개 이상 언어 실무 수준
- 우대: 깃허브 포트폴리오, 클라우드 자격증(AWS SAA 등), SI·스타트업 인턴 경험
- 어학: 토익 750~800 (내부 컷), 영어 기술문서 독해

## 데이터 분석·AI

- 필수: SQL, Python(pandas), 통계 기초
- 우대: 통계·산업공학 전공, 캐글·데이콘 수상, 머신러닝 프로젝트
- 가산: 빅데이터 분석기사, ADsP

## 기획·마케팅(IT 서비스)

- 필수: 서비스 기획서 작성 능력, 지표 분석(로그 기초)
- 우대: 상경계열 전공, GA/GMP 자격증, IT 부트캠프·해커톤 경험
- 어학: 토익 스피킹 중급 이상 (글로벌 서비스 팀)

## 공학계열 vs 상경계열 준비 전략 요약

| 구분 | 공학계열 | 상경계열 |
|---|---|---|
| 핵심 무기 | 직무 자격증 + 프로젝트 포트폴리오 | 어학 + 문서 분석 역량 |
| 추천 자격증 | 빅데이터 분석기사, AWS, 정보처리기사 | ADsP, 컴활 1급, 전산회계 |
| 인턴 경로 | 현장실습학기제, 연구실 | 학생회·대외활동, 공모전 |
