## 1. 교과목 개요

공학 문제를 수학적으로 모형화하고 해석하는 데 필요한 미분방정식과 관련 수학 도구를 학습한다. 1계 미분방정식의 여러 해법, 2계 및 고계 선형 미분방정식, 라플라스 변환, 급수해법을 다룬다.

**주교재**: Erwin Kreyszig, "Advanced Engineering Mathematics" (10th ed.), Wiley
**부교재**: 김응박 외, 『공학수학』, 이한출판사

## 3. 주차별 강의 계획

| 주차 | 강의 내용 |
|---|---|
| 1주 | 오리엔테이션, 미분방정식 소개: 기본 개념과 모형화 |
| 2주 | 1계 미분방정식(1): 변수분리법, 동차형 |
| 3주 | 1계 미분방정식(2): 선형 미분방정식, 적분인자 |
| 4주 | 1계 미분방정식(3): 완전미분방정식, 베르누이 방정식 |
| 5주 | 1계 미분방정식의 응용: 냉각법리, 혼합 문제, 직류회로 |
| 6주 | 2계 선형 미분방정식(1): 동차 방정식, 특성방정식 |
| 7주 | 2계 선형 미분방정식(2): 감쇠 진동, 강제 진동, 공진 |
| 8주 | **중간고사** |
| 9주 | 2계 비동차: 미정계수법 |
| 10주 | 2계 비동차: 매개변수변화법, 코시-오일러 방정식 |
| 11주 | 라플라스 변환(1): 정의, 기본 변환, 역변환 |
| 12주 | 라플라스 변환(2): 도함수의 변환, 초기값 문제에의 적용 |
| 13주 | 라플라스 변환(3): 단위계단함수, 합성곱(convolution) |
| 14주 | 급수해법: 멱급수 해, 프로베니우스 방법 |
| 15주 | **기말고사** |

- 주차별 연습문제 중 5~8문제를 지정해 LMS에 공지 (총 4회)
